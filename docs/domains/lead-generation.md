# Domain: Lead Generation

## Purpose

Capture demand, qualify it, route it to the right providers or internal ops, and attribute outcomes.

## Responsibilities (logical)

- Lead intake (web, API, partners)
- Validation and enrichment hooks
- Routing rules and SLAs
- Attribution and conversion tracking

## Non-responsibilities

- Long-running relationship management → CRM
- Fulfillment of the HVAC job → ERP / operations

## Dependencies

- Directory (provider eligibility)
- Notifications
- Public REST API (partner intake)
- Identity / consent / privacy controls

## Implementation status

Documentation only. No business logic in repository yet.
