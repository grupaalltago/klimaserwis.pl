# UX — MVP Klimaserwis.pl

**Role:** Senior Product Designer / UX Architect  
**Scope:** Absolute minimum viable product launchable in **7 days**  
**Output:** UX documentation only — no application code  

## Design thesis

Ship the smallest product that can:

1. **Rank** for HVAC intent in Poland (SEO)  
2. **Capture** demand as leads (lead generation)  
3. **Prove** providers are real and accountable (trust)  
4. **Convert** visitors into submitted requests (conversion)  

Everything else is deferred.

## Non-goals (cut for 7-day MVP)

| Cut | Why |
|---|---|
| User accounts / login | Slow; not required to capture leads |
| CRM / ERP / AI / mobile apps | Post-MVP platform |
| Paid ads landing system | Organic + direct first |
| Advanced filters (10+) | One search + 3 filters max |
| Messaging / chat | Form is enough |
| Provider self-serve onboarding portal | Manual/ops seed data for launch |
| Reviews write-flow | Show trust signals; collect reviews offline if needed |
| Multi-city microsites | One national IA; city via search/URL later |
| Comparison tables, quotes engine | Premature |

## Value filter

A feature ships only if it does at least one of: **SEO indexable surface**, **lead capture**, **trust cue**, **conversion assist**.

## Success metrics (launch week)

| Metric | Target intent |
|---|---|
| Lead submit rate (sessions → successful form) | Primary KPI |
| Indexable profile + blog URLs live | SEO foundation |
| Time-to-first lead | Operational proof |
| Form completion without error | Conversion quality |
| Bounce on profile with CTA visible | Trust + clarity |
